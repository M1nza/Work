# Personal Portfolio Website

A modern, interactive personal portfolio website built to showcase my projects, technical skills, and experience.

The website features responsive design, updated styling, interactive UI elements, and a **3D model powered by Three.js**. It is deployed using **GitHub Pages**.

## Features

- Responsive and modern user interface
- Interactive 3D model using Three.js
- Project and skills showcase
- Smooth animations and interactive elements
- Updated visual styling and layout
- GitHub Pages deployment

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- GitHub Pages
